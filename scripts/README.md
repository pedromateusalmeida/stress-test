# Scripts

- `executar_notebooks.py`: executa um intervalo inclusivo de notebooks e salva suas saídas. Uso padrão: `python -u scripts/executar_notebooks.py 01 17`.
- `sintetizar_respostas.py`: recria as sínteses univariada/multivariada a partir das tabelas 04/05.
- `auditar_variante.py`: checagem técnica de execução, artefatos e colunas; não certifica validade econômica.
- `extrair_figuras_relatorio.py`, `criar_figuras_pdf.py`, `renderizar_relatorio_pdf.py`: manutenção das figuras e da versão PDF do relatório.

Execute os comandos a partir da raiz do repositório. Veja [Guia de execução](../docs/GUIA_DE_EXECUCAO.md) e [Metodologia](../docs/METODOLOGIA.md).
