# Referências históricas de modelagem

- `model_final.ipynb` é o notebook de modelagem fornecido como referência histórica.
- `historico/` contém notebooks exploratórios e módulos auxiliares anteriores: `teste CSL.ipynb`, `Teste Oversampling.ipynb`, `Untitled.ipynb`, `utils.py` e `utils_eda.py`.

Nas **cópias deste projeto**, código e células Markdown dos notebooks são preservados; saídas e contadores de execução foram removidos para retirar tracebacks e caminhos locais antes de publicar. Os arquivos originais fora desta pasta Git permanecem intactos. Os módulos `.py` históricos permanecem como referência, não como dependência da suíte.

Esses arquivos documentam a proveniência e as tentativas anteriores; **não fazem parte do fluxo executável** do projeto organizado. O Booster usado nos testes está em [models/](../models/) e foi retreinado com o peso positivo solicitado. Compare manifesto e hashes antes de atribuir resultados ao objeto original `model_class`.

Para reproduzir os testes atuais, siga o [guia](../docs/GUIA_DE_EXECUCAO.md), não esses notebooks de referência. Antes de publicar outras cópias ou alterações, revise novamente outputs e caminhos locais.
