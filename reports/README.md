# Relatório

[RELATORIO_DIDATICO.md](RELATORIO_DIDATICO.md) é o texto editável; [RELATORIO_DIDATICO.pdf](RELATORIO_DIDATICO.pdf) é a versão para leitura/distribuição. O documento parte da pergunta “quanto drift o modelo tolera?”, define termos e fórmulas, descreve métodos, apresenta resultados e literatura, e expõe os limites de interpretação.

`figuras_relatorio/` contém **quatro figuras selecionadas como exemplos**. O relatório não tenta reproduzir todos os milhares de pontos em suas páginas. Para as dez entradas e os 45 pares, use [notebook 17](../notebooks/17_atlas_todas_variaveis_e_pares.ipynb), os PNGs em [results/figures](../results/figures/) e as tabelas completas.

Os números pertencem ao Booster e aos CSVs identificados pelo manifesto. Se modelo ou dados mudarem, atualize também resultados e interpretação do relatório.
